IoT-Based Dynamic Lighting Control for Controlled Environment Agriculture

  Honours Project — BSc Software Development
  Glasgow Caledonian University — 2025/26
  Student: Ashley Dunn 
  Supervisor: Muhammad Ayub Ansari

Overview:

  This project designs, implements and validates an IoT-based dynamic LED control system capable of reproducing historical solar diurnal spectral energy profiles indoors. Rather than using conventional static lighting recipes, the system derives hourly spectral targets from real historical solar irradiance data and evaluates three actuator models against those targets under both scaled and unscaled conditions.
